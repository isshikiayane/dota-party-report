Dota 2 开黑档案 · Windows 免安装版
====================================

使用方法

1. 必须先完整解压本压缩包，不要直接在压缩软件里运行。
2. 双击“启动 Dota 2 开黑档案.bat”。
3. 浏览器会自动打开；输入 2–5 个 Dota Account ID 即可。
4. 黑色窗口需要保持开启。关闭窗口后，本地网页就会停止。

如果浏览器没有自动打开，请手动访问：
http://localhost:3000

支持的账号格式

- Dota Account ID
- Steam64 ID
- 末尾包含数字 ID 的 Steam / OpenDota 个人资料链接

数据说明

本工具读取 OpenDota 的公开数据。玩家隐藏比赛数据、比赛尚未解析或旧记录字段缺失时，统计结果可能少于 Dota 2 客户端显示的官方数据。

隐私说明

查询结果只缓存在当前电脑中。查询时账号 ID 会发送给 OpenDota 公开接口，不会发送给本工具作者。

常见问题

- 本工具默认只允许当前电脑访问，不需要向局域网或公网开放端口。
- 显示端口被占用：先关闭之前打开的“Dota 2 开黑档案”黑色窗口，再重新启动。
- 查询失败或很慢：稍后重试，或者配置自己的 OpenDota API Key。
